# 桌宠项目 (table-pet) 实现计划

## 技术栈
- **Tauri v2** + **Vue 3** + **Vite** + **TypeScript**
- **pnpm** 包管理器
- **Rust** 后端（sysinfo crate 采集系统信息）

## 前置条件检查
- [ ] 确认 Node.js、pnpm 已安装
- [ ] 确认 Rust 工具链已安装（`rustc --version`）
- [ ] 如未安装 Rust，引导用户运行 `rustup` 安装

## 分步实现

### Step 1: 项目初始化
- 用 `pnpm create tauri-app` 创建 Tauri + Vue + TS 项目
- 安装依赖：`pnpm install`

### Step 2: Tauri 窗口配置 (`tauri.conf.json`)
- `decorations: false` — 无边框
- `transparent: true` — 透明背景
- `alwaysOnTop: true` — 置顶
- `width/height: 300` — 小窗口
- `position: "bottomRight"` — 默认右下角

### Step 3: Rust 系统信息采集
- 添加 `sysinfo` crate 依赖
- 实现 Tauri command `get_system_info`：
  - CPU 使用率
  - 内存使用率 / 已用 / 总量
  - 磁盘使用率
  - 系统运行时间
- 返回结构化 JSON 给前端

### Step 4: 前端 — 桌宠角色 (`Pet.vue`)
- CSS 绘制占位符角色（圆形身体 + 表情 + 小手小脚）
- CSS 动画：待机呼吸、开心跳动、困倦摇晃
- 根据心情状态切换动画

### Step 5: 前端 — 系统信息面板 (`InfoPanel.vue`)
- 悬浮在桌宠旁边的信息卡片
- 显示 CPU / 内存 / 磁盘进度条
- 使用 `useSystemInfo` composable 每 2 秒轮询

### Step 6: 前端 — 拖拽交互
- `App.vue` 中使用 Tauri 的 `startDragging()` API 实现原生拖拽
- 左键点击触发桌宠反应（开心动画）

### Step 7: 前端 — 对话气泡 (`ChatBubble.vue`)
- 点击桌宠弹出气泡
- 根据系统状态生成智能回复（如"内存快满了，要不要清理一下？"）
- 随机闲聊语句
- 时间感知（早上好、下午好、该休息了）

### Step 8: 前端 — 右键菜单 (`ContextMenu.vue`)
- 显示/隐藏系统信息
- 设置（透明度调节）
- 退出

### Step 9: 桌宠状态管理 (`usePetState.ts`)
- 心情状态：happy / normal / sleepy / warning
- 根据系统指标自动切换心情：
  - CPU > 80% → warning
  - 内存 > 85% → warning
  - 深夜时段 → sleepy
  - 正常 → happy/normal

### Step 10: 构建与运行
- `pnpm tauri dev` 开发调试
- `pnpm tauri build` 打包为独立 .exe

## 关键交互设计

| 操作 | 效果 |
|------|------|
| 左键点击桌宠 | 弹出对话气泡 |
| 左键拖拽桌宠 | 移动窗口位置 |
| 右键点击桌宠 | 弹出设置菜单 |
| 双击桌宠 | 打开/收起系统信息面板 |

- 圆形身体 + 圆耳朵
- 表情眼睛（根据心情变化）
- 小手小脚（待机时轻微摆动）
